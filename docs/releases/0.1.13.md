# Talos CLI 0.1.13

Emergency patch: a custom or gateway model can turn image input on or off in `/model`.

## Changes

- In `/model`, Alt+I toggles image input for a custom model. The choice is saved on that model as image input plus `support_image`, so the next turn sends images.
- A custom model with no saved vision choice inherits image input when every catalog source for that exact id agrees it accepts images. A conflicting or unknown id stays text until Alt+I.
- Classic remains the default skin.
