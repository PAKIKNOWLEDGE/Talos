# Talos CLI 0.1.7

Patch release: optional Collapsal TUI skin. Classic remains the default.

## Changes

- Add `/settings` Interface page for Classic and Collapsal. The chosen skin is boot-frozen and applies after restart; `/theme` still changes colors live.
- Collapsal fullscreen pins version, model, and path above the transcript.
- Collapsal default footer is `cwd | git | model | remaining context` (no stars or permissions badge). Configured `/statusline` items, including exclusive `build-mode`, are unchanged.
- Collapsal user messages render as ❯ bubbles; assistant turns get a hairline separator.
