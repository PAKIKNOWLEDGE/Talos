# Talos CLI 0.1.10

Patch release: `web_search` uses pluggable Tavily / Exa / DeepSeek backends from `/settings`. Matrix search is removed. Welcome notes keep the 0.1.9 Collapsal, permission-footer, and boot-sound bullets.

## Changes

- Native `web_search` stays registered. `/settings` → Web search selects Auto, Tavily, Exa, or DeepSeek and stores API keys in `config.yaml`.
- Auto walks configured keys (Tavily, then Exa, then DeepSeek). Missing credentials return a `/settings` error instead of hiding the tool or calling Matrix.
- Environment keys (`TAVILY_API_KEY`, `EXA_API_KEY`, `DEEPSEEK_API_KEY`) still work. Collapsal, Classic, boot sound, and `Alt+M` are unchanged.
