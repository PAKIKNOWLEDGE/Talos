# Talos CLI 0.1.12

Patch release: Welcome shows this version's changelog notes in order. `/rules` can view, filter, and delete saved permission rules. A typed deny reason reaches the model, and Enter during a live reply stops that reply.

## Changes

- Welcome no longer picks three changelog bullets at random. It shows the first bullets of this version, in changelog order. `/changelog` still has the full history.
- `/rules` lists saved allow, deny, and ask rules. `d` deletes the selected rule. `f` cycles deny, allow, then everything. The selection stays on screen while the list scrolls.
- Deny and guide appends the typed reason to the tool denial the model reads. The saved rule stays a path or command rule and does not store that text.
- Enter during a live reply stops the current reply and sends the draft in the same turn. Alt+Enter still queues. Esc still stops the turn.
- Classic remains the default skin.
