# Talos CLI 0.1.8

Patch release: interactive TUI boot sound. Welcome notes keep the 0.1.7 Collapsal bullets and add the sound.

## Changes

- Interactive TUI plays a short PCM WAV at startup. Classic and Collapsal both play it. Login restart does not play it again.
- Windows uses `System.Media.SoundPlayer`. Linux tries `pw-play` then `paplay`. A missing player stays silent and does not block launch.
- Collapsal interface from 0.1.7 is unchanged.

## Validation

- Focused Vitest: startup-sound policy and Windows/Linux spawn, packaged changelog 0.1.8 notes.
- Windows boot sound heard from `pnpm start` after the non-detached player fix.
- Linux/NixOS playback is untested in this release (fail-silent).
- `pnpm verify --profile windows` **PASS** at `8e5e7b1` (~123s).
