# Talos CLI 0.1.14

Patch: a long chat that keeps pictures no longer resends every original picture at full size.

## Changes

- PNG and JPEG pictures are reduced on the outbound copy. The saved chat still holds the originals.
- When the request is still too large, the oldest pictures become a short note and the newest stay. A model that declares a request size uses that size. A gateway that does not declare one is remembered after the first size refusal, at the last size that went through.
- Raising the limit, or switching to a model with a higher limit, sends the saved pictures again.
- Version commits and tags now say Talos, not MiniMax Code.
- Classic remains the default skin.
