# Talos CLI 0.1.11

Patch release: Collapsal Welcome shows System notes; `/sessions` adds permanent delete (Ctrl+X twice) while keeping archive. Welcome notes keep the 0.1.10 Web search, Collapsal, and boot-sound bullets.

## Changes

- Collapsal Welcome: System notes are a titled full-width block with wrapping. Classic Welcome is unchanged.
- `/sessions`: Ctrl+D archives; Ctrl+X twice wipes the session. Esc cancels. TUI only; Desktop and ACP delete mapping are unchanged.
- Classic remains the default skin.
